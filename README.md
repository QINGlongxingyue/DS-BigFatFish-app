# DSAI — 大肥鱼 × DeepSeek 的 Live2D 手机助手

跑在安卓手机上的 Live2D 桌宠加 AI 助手。屏幕上是会眨眼、会盯着你看、说话时嘴会动的大肥鱼，
打字或者用语音跟她聊都行，她会回话，能出声念出来，也会看自己回复里的情绪词做表情。

对话走 DeepSeek 官方接口；语音识别在本机离线跑，不联网、录音也不出手机；
朗读用豆包（火山引擎）的双向流式 TTS；需要查资料的时候能联网搜。

## 功能

- **桌宠**：两个模型，右上角一键切换。大肥鱼是默认那个蓝鲸女孩，带 15 个表情；另一个是 DeepSeek 官方鲸鱼，自带待机、说话、思考三组动作。
- **对话**：DeepSeek 官方接口。模型可以在设置里换：标准、深度思考（更聪明，回得慢）、快速。
- **表情动作**：回复里出现开心、生气、害羞、思考、好吃这类词，她会自己做个表情或者动作，随机过 4 到 7 秒淡回原样。
- **语音输入**：左下角电话图标按一下就开始听，说完停两秒半自动断句，识别出来的话直接发出去，不用你再点发送。识别模型内置在 App 里，不联网、不花钱。
- **语音朗读**：回复自动念出来，嘴型跟着声音大小动。朗读的时候麦克风会让开，免得她把自己念的内容又听一遍。要填豆包的凭据才有。
- **联网搜索**：默认用内置搜索，不用申请任何 Key；也可以换成博查（中文好、国内直连）或 Tavily（英文好）。
- **对话存档**：每段对话存成一条，列表里能看到标题、条数、时间和最后一句，随时切回去接着聊。
- **人设与记忆**：系统提示词可以自己改，还能另外贴一段希望她长期记住的资料。
- **时间**：每次请求都会告诉她今天几号、星期几、现在几点，问日期不用她猜。
- **位置与大小**：单指拖动、双指缩放，两个模型分开记各自的设置。

## 安装

1. 下载 Releases 里的 `DSAI.apk`，或者自己构建（见下面）。
2. 手机上允许安装未知来源的应用。
3. 装好打开。

第一次打开要加载模型，一两秒内画面是空的，等一下就好。

## 首次设置

点左上角齿轮进设置。下面这些只有第一项必须填。

| 设置项 | 填什么 |
|---|---|
| API Key | 到 platform.deepseek.com 申请，`sk-` 开头。不填聊不了 |
| 模型 | 标准（默认）、深度思考、快速。一般用标准就行 |
| 系统提示词 | 留空就用内置的大肥鱼人设。想换性格或说话风格就自己写 |
| 辅助记忆文档 | 想让她长期记住的东西贴这儿，每次对话都会带上 |
| 联网搜索 | 内置搜索不用管；要更好的效果就选博查或 Tavily，填上各自的 Key |
| 语音输入灵敏度 | 正常音量说话用标准。环境吵（风扇、空调）换抗噪，说话小声换灵敏 |
| 语音朗读 | 火山引擎控制台的 App ID、Access Token、音色 ID。资源 ID 默认 `volc.megatts.default`，填完可以点「试听一句」验一下 |
| Live2D 显示 | 点「调整位置和大小」进去调，见下面 |

豆包那两个凭据要从控制台同一个应用里复制，混着用会报 grant not found。自己复刻的音色 ID 是 `S_` 开头。

## 怎么用

### 聊天

输入框打字，点发送或者按回车。配了语音朗读的话她会念出来，回复里带情绪词会自己做表情。

### 语音输入

点左下角电话图标开始。图标变红、外面一圈在呼吸，就说明正在听。
说完停两秒半，她自动断句、识别、直接把这句话发出去。
等回复和朗读的时候麦克风会让开，念完自己接着听。
不想聊了再点一下电话图标关掉，关的时候也会把最后半句识别出来。

### 联网搜索

输入框左边的放大镜点亮以后，每条消息都会先查资料再回答。这个状态会记住，下次打开还是这样。
不点亮的时候，消息里出现最新、查一下、天气、股价这类词，或者是个问句，也会自动去查。
查到的资料会连链接一起给她，并要求她标出来源，查不到就说查不到。

### 对话存档

点左上角气泡图标。每段对话一行，标题取她说的第一句话，没有就用时间。
点整行切回去接着聊，右边垃圾桶删掉（会问一次）。
顶部「＋ 新对话」开一段新的，开之前会先把现在这段自动存进去，不会丢。

### 调整位置和大小

设置 → Live2D 显示 → 调整位置和大小，设置会自动关掉。
在舞台里单指拖动是移动，双指捏合是缩放。
调好点右上角完成，会按模型分别记住。点「恢复默认」可以还原。

## 从源码构建

需要 JDK 17 以上（Android Studio 自带的就行）和 Android SDK。

```
# 在 DSAIAPP 目录下
./gradlew :app:assembleDebug      # 调试包
./gradlew :app:assembleRelease    # 发布包，R8 压缩后小很多
```

产物在 `app/build/outputs/apk/` 下面。release 用的是 debug 签名，可以直接装。
也可以直接用 Android Studio 打开 `DSAIAPP` 目录，同步完点运行。

包体大是因为内置了离线语音识别模型（`app/src/main/assets/asr/model.int8.onnx`，约 78MB）
和 sherpa-onnx 运行时，换来的是不用联网、不额外花钱的本地识别。

## 常见问题

**没有声音，或者不朗读**
先看手机媒体音量。再去设置里确认语音朗读的 App ID、Access Token、音色 ID 都填了，点「试听一句」试试。

**语音识别没反应**
设置里把灵敏度调到灵敏；说话离麦克风近一点。电话模式开着的时候图标是红色呼吸的。

**搜索查不到东西**
内置搜索是解析 Bing 网页，Bing 改版了就可能失效。换成博查，填上 Key 就好。

**屏幕不会自己黑**
故意的。前台保持常亮，免得语音聊天中途息屏断掉。切到后台会立刻放开麦克风和播放。

**她不知道今天几号**
不会，每次请求都会把日期、星期、时间告诉她。
